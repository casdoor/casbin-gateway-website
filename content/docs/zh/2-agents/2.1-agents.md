**Agent客户端**是首页。本机装的每个AI编码Agent都在这儿，一行四张卡片。

[![Agent客户端](/casbin-gateway.gif)](/casbin-gateway.gif)

每张卡片给出：

- 它登录的**账号**，
- 它使用的**供应商**，
- 它**花了多少**——只要它自己的会话记录能追溯到，就按天铺开最近一个月，
- 以及它**此刻是否在运行**。

本机没装的Agent也会列出来，方便直接从这一页装上。

## Agent是怎么找到的

Gateway会读**它自己所在这台机器**的用户账户、主目录和安装路径，覆盖安装程序写出的那些目录布局，也覆盖手动解包、放进PATH的情况。

要是某个Agent藏在两者都描述不了的地方，就直接指给它：**选择程序**可以浏览本机，把你挑中的程序作为一个独立的安装列出来，不移动也不修改任何东西。

这也是Gateway必须跑在目标机器上的原因——容器里它读的是容器自己的文件系统，什么都找不到（[5.4](../5-operations/5.4-docker.md)）。

## 启动与停止

**启动**和**停止**就在卡片上。从Gateway启动的Agent，和你自己启动的是同一份安装，Gateway只负责把它拉起来。

## 账号

Codex同时只保留一份登录信息，它自己的登录会覆盖原有的那份。所以对Codex——CLI和ChatGPT桌面应用共用这份登录——Gateway会保存副本：ChatGPT订阅账号和API密钥可以同时留在手上，在它们之间切换只需点一下，不用重新登录。

卡片上的**账户**选择器显示当前在用的登录，并能把Agent切到另一个已保存的账号。Agent自己的页面上有完整的**账号**表：

| | 作用 |
| --- | --- |
| **登录** | 用一个独立的目录运行Codex自己的浏览器登录，所以当前在用的账号不受影响，登录回来的账号会被保存下来 |
| **添加API密钥** | 按Codex自己的格式保存一个密钥。切换过去后，Codex改用密钥而不是账号登录 |
| **切换** | 把这份已保存的登录放回去 |
| **剩余用量** | 订阅账号才有：短周期（五小时）和每周两个额度各剩多少、各自什么时候重置，以及账号还剩几次重置额度。Gateway用那个账号自己的令牌向OpenAI查询。密钥没有套餐额度，显示为`-` |
| 垃圾桶 | Gateway删除它保存的副本。Codex当前登录的账号保持不变 |

每个账号的名字可以直接在表里改，这样同一套餐的两个账号不用看邮箱就能分清。

**Gateway没有副本的登录**，一旦切换就会丢失，所以页面会提示出来，并在你选别的账号之前提供**保存当前登录**。

Agent在启动时读取登录信息。它运行期间切换账号，会提示**重启Agent后生效**；在那之前它继续用启动时的那个账号。

## 实例

**实例**是同一个Agent的各个副本，每个有**自己的状态目录**，因此各自登录各自的账号，并且可以同时运行——最常见的理由是开几个Claude Desktop，一个账号一个。

安装本身就是第一个，列为**默认实例**：它运行在Agent默认使用的状态目录上。它以安装本身命名，不能重命名，也不能移除。

- **添加实例**再新建一个。
- **移除实例**只是让Gateway忘掉它。状态目录和登录在里面的账号都留在磁盘上。

只有Gateway知道怎么给它另配状态目录的Agent，才有实例。
